# 📱 FinSphere Calc — Financial Calculator Application

*A comprehensive mobile application built using Flutter and Firebase that simplifies complex financial calculations, offering tools for loan EMIs, investment planning, date comparisons, and visual data breakdowns[cite: 1].*

*Designed to showcase modern mobile application development, clean UI/UX design, and robust financial computing, suitable for academic projects, portfolios, and client-focused deployments.*

---

## 📌 Project Overview

This project models a real-world digital financial calculator platform including[cite: 1]:

* **Loan & Debt Calculations:** Home Loan, Personal Loan, Car/Bike Loan, and Education Loan EMIs[cite: 1].
* **Investment & Wealth Tools:** SIP Calculator, Mutual Fund Return Estimator, and Lumpsum Investment Calculator[cite: 1].
* **Advanced Utilities:** Side-by-side Loan Comparison tool and a Date Calculator for duration and schedule planning[cite: 1].
* **Data Visualization:** Interactive Donut/Pie charts depicting principal vs. interest distributions[cite: 1].

## 🔹 Features Implemented

### 1️⃣ Authentication & User Management
* Secure Login and Signup screens with role-based routing (User vs. Admin)[cite: 1].
* Password visibility toggle and input validation[cite: 1].
* Admin module to oversee accounts and monitor system usage[cite: 1].

### 2️⃣ Core Financial Calculators
* Instant computation of monthly EMIs, total interest payable, and total repayment amounts[cite: 1].
* Support for variable tenures, fluctuating interest rates, and principal adjustments[cite: 1].

### 3️⃣ Interactive Visualizations & Analysis
* **Pie Chart / Donut Chart Screen:** Visual breakdown highlighting the ratio of Total Principal vs. Total Interest[cite: 1].
* **Loan Comparison Tool:** Side-by-side slider controls to evaluate two distinct loan options simultaneously, complete with an automated EMI difference summary card[cite: 1].

### 4️⃣ Utility Modules
* **Date Calculator:** Toggle between calculating the precise difference between dates or adding custom durations (Years, Months, Days) to a reference start date[cite: 1].

## 📂 How to Run This Project

1. Clone the repository and open it in your preferred IDE (e.g., Android Studio / VS Code with Flutter SDK installed).
2. Configure your Firebase project and link `google-services.json` / `GoogleService-Info.plist`[cite: 1].
3. Run `flutter pub get` to install dependencies.
4. Connect an emulator or physical device and execute `flutter run`.
